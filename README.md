# DAY 1-22 통합 · 50 단어 퀴즈

1~22일차 단어 중 50개를 추출한 인터랙티브 어휘 퀴즈입니다.
객관식/주관식 모드, 한글뜻·유의어·반의어 필터, 오답 복습 기능을 제공합니다.

## 실행 방법
`index.html`을 열면 바로 실행됩니다. GitHub Pages로 배포하려면
이 저장소를 GitHub에 올린 뒤 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로 설정하세요.
배포 후 `https://사용자명.github.io/저장소명/` 주소로 접속해 풀 수 있습니다.
